# T113 智慧屏改板：新增 UART / I²C 接口（四层板）

给一块"边缘 AI 显示终端"补上两路接口的一版**改板**：
一路 **UART** 连 RV1106 推理板，一路 **I²C** 连温湿度传感器，最终实现「采集 → 端侧推理 → 屏幕响应」的闭环。

> ⚠️ **边界说明**
> 主板原理图与初始布局来自公开的 **T113 智慧屏参考工程（作者 V2 版）**。
> 本仓库记录的是**我做的改动、验证过程与投产包**，不是从零设计的整板。
> 参考设计未经授权不随仓库分发。

## 二、我做了什么

### 1. 引脚规划与三处冲突排查

改板最容易翻车的地方是**引脚被别的功能占着**。逐个核实（依据 T113-S3 数据手册 v1.6 pp.40–42 复用表 + 原理图 + EDA 网络搜索）后，确定：

| 新增接口 | 控制器 | 引脚 | 网络名 | 结论 |
|---|---|---|---|---|
| → RV1106 串口 | **UART5** | `PB4`(TX) / `PB5`(RX) | `UART5_TX` / `UART5_RX` | ✅ 可用（见下） |
| → 温湿度传感器 | **TWI0** | `PG12`(SCL) / `PG13`(SDA) | `SENS_SCL` / `SENS_SDA` | ✅ 空闲 |

**核心判断：UART5 与触屏的 TWI1 在复用表上"重叠"，但冲突并不成立。**

- PB4 / PB5 同时是 `TWI1` 与 `UART5` 的候选脚（数据手册 p.40），第一眼看上去是硬冲突
- 但核对原理图后发现：触屏实际接的是 TWI1 的**另一组引脚 `PE0` / `PE1`**
- 也就是说，**PB4/PB5 上的 TWI1 功能从未被启用**
- 因此在 PB4/PB5 上使用 UART5 **不影响触屏**，方案成立

> 由此确立了一条判定方法：
> **"复用表重叠"只说明"可能冲突"，必须回到原理图确认那个复用功能是否真的被启用。**

**另外两处绕开的点：**

1. **UART4 的首选脚 `PB2` 被功放使能（`PA_SHDN`）占用** —— 这也是最终没有选 UART4 的原因之一。
2. **触屏已占 TWI1，传感器不能再挂同一条总线** —— 另开 **TWI0（`PG12`/`PG13`）**，
   并在 EDA 里确认这两个脚**无任何网络命中**才敢用。

**新增电路还包括**：UART5 端子（`U55`）处的 **ESD 保护（`ESD5451N`，`U56`/`U57`）**，
器件紧贴端子放置以缩短泄放路径。

### 2. I²C 上拉电阻重新计算

两个约束夹逼：

```
灌电流下限：R_min = (VDD − VOL_max) / I_OL = (3.3 − 0.4) / 3 mA ≈ 967 Ω
上升时间上限：R_max ≈ t_r / (0.8473 × C_bus) ≈ 1 µs / (0.8473 × 50 pF) ≈ 23.6 kΩ
```

→ 可接受范围约 **1 kΩ ~ 24 kΩ**，取 **4.7 kΩ**。

> **顺带纠正了一个文档错误**：迁移文档写"已有 4.7 kΩ 上拉"，但核对原理图后发现实际只有一组
> **10 kΩ 排阻 RN1**，4.7 kΩ 是理论推算被误记成了实装器件。
> 结论因此从"加上拉会过强"改为"新总线需要自己配上拉"。

### 3. 阻抗与叠层的工程判断（本版未做阻抗管控）

MIPI DSI 实际速率估算：

```
280 × 1424 像素 × 24 bit × 60 fps ≈ 574 Mbps（合计）
÷ 4 lane ≈ 144 Mbps / lane
```

144 Mbps/lane 远低于 MIPI D-PHY 每 lane 1 Gbps 以上的上限，**阻抗偏差带来的眼图收缩有余量**。
因此本版按板厂标准叠层生产、不做阻抗管控，并把它列为**第二版的可选优化项**。

> 这是一个有量化依据的取舍，不是"作者不做我也不做"。

### 4. 天线净空分析

对 WiFi/BLE 天线周边的铺铜与走线做了净空核查，对比图见 [`docs/img/`](docs/img/)，
分析过程见 [`docs/天线净空分析_2026-09-30.md`](docs/天线净空分析_2026-09-30.md)。

### 5. 投产包与 DFM 核对

投板前按板厂工艺能力逐项核对，发现实际最小线宽/间距（4.88 / 4.02 mil）与最小孔径（0.305 mm）
都接近工艺下限——原因是 0.4 mm 引脚间距的逃逸走线所迫。确认可行后，把**真实参数**写进投产文件，
避免按错误的设计规则下单。
