# 叠层参数速查 + 跟客服的确认话术

> **日期**：2026-09-24
> **背景**：已定"代工厂打板 + 代工厂贴片"，阻抗控制默认不做；客服收了 Gerber/BOM/坐标后只说"等报价"，没提叠层
> **结论写在最前面**：⭐ **这是正常的，不用追问。** 理由见 §1。

---

# 1. ⭐ 为什么客服不问叠层是正常的

**因为参数分两个层级，报价阶段只需要第一层。**

| 层级 | 参数 | 谁在什么时候需要 | 你的状态 |
|---|---|---|---|
| **报价级** | **层数（4）、板厚（1.6mm）、铜厚（1oz）、尺寸、表面处理、最小线宽/孔径、数量** | 客服**报价格**时必须知道 | ✅ **已经全给了**（在 `PCB_SMT_Requirements_2026-09-24.txt` 里） |
| **生产级** | **叠层结构表**：每层介质厚度、铜厚、板材/PP 型号、Dk… | **工程部在下单/审单时**排生产才需要 | 🔲 等报价出来后要 |

**另外两条让这件事更不紧急：**

1. **4 层 1.6mm FR-4 是行业标准品。** 板厂有固定的常备叠层，不会因为你没指定就乱做。
2. **阻抗管控是收费项。** 你明说不做阻抗，板厂就**没有理由**在报价阶段跟你核叠层
   ——核了也是白核，因为你不付这个钱。

**⚠️ 只有一种情况要立刻管**：他们回话说"我们 4 层板叠层和嘉立创不一样，需要你确认"。
不说就是按他们的标准叠层走。**主动去要，但不用现在急。**

---

# 2. 叠层参数到底包括哪些（完整清单）

一张合格的**叠层结构表（叠层图）**应该包含下面四组。

## 2.1 结构组（谁在哪一层）

| 参数 | 说明 |
|---|---|
| **层序与层名** | L1 顶层 / L2 中间1 / L3 中间2 / L4 底层 |
| **层属性** | ⭐ 是**信号层**还是**平面层（GND / VCC）** |
| **叠层顺序** | 本板 = `信号 — GND — VCC — 信号`（作者原设计，见 `2、硬件设计.md` §叠层设计） |
| **对称性** | 4 层板通常要求对称压合，防止翘曲 |

## 2.2 厚度组（最关键的一组）

| 参数 | 说明 | 本板值 |
|---|---|---|
| **成品总厚 + 公差** | 含阻焊油墨 | **1.6 mm ±10%** |
| ⭐ **介质厚度（压合后）** | ⭐ **每两张铜层之间的树脂厚度** —— **这是决定阻抗的那个数** | 由板厂给 |
| **铜厚（外层 / 内层）** | 常用成品铜厚：外层 1oz、内层 0.5oz 或 1oz | 外层 1oz、内层按板厂默认 |
| **芯板（core）厚度** | 中间的刚性基材厚度 | 由板厂给 |
| **半固化片（PP）型号** | 如 `3313`、`2313`、`1080`、`2116` —— **型号决定单张 PP 压合后的厚度** | 嘉立创是 `3313` |
| **阻焊层厚度** | 分三种：基材上（C1）、铜面上（C2）、线间（C3） | 见 §3 |

## 2.3 材料组（批次一致性的保证）

| 参数 | 说明 |
|---|---|
| **板材型号** | 例如嘉立创 4–8 层默认 **南亚 NP-155F**；8 层以上用生益 S1000-2M |
| **PP（半固化片）型号** | 同上 |
| **铜箔类型** | 常规电解铜箔 |
| **阻焊油墨型号** | 影响 Dk 和成品厚度 |
| **表面处理** | 沉金 ENIG / 喷锡 HASL —— 影响成品厚度与可焊性 |

## 2.4 电性组（阻抗计算的输入）

| 参数 | 说明 |
|---|---|
| **介电常数 Dk（Er）** | 板材的介电常数，**阻抗 ∝ 1/√Dk** |
| **损耗因子 Df** | 高频衰减，本板低速，可忽略 |
| **阻焊 Dk** | 嘉立创取 **3.8** |

# 3. ⭐ 关键：真正影响阻抗的只有 5 个量

**叠层表上参数一大堆，但阻抗公式里只有这五个：**

| 符号 | 含义 | 在叠层表里的位置 |
|---|---|---|
| **H** | ⭐ 信号层到**参考平面**的**介质厚度** | 叠层表里 **L1→L2** 那一行 |
| **W** | 线宽 | 你的 PCB 设计（6 mil） |
| **S** | 差分线距 | 你的 PCB 设计 |
| **T** | 铜厚 | 叠层表里外层铜厚 |
| **Er** | 介电常数 | 叠层表里板材的 Dk |

> **⭐ 一句话**：所谓"要叠层参数"，本质上就是**要一个 H** ——
> 顶层走线到 L2（GND）的介质厚度。
> 作者的 6mil 线宽和差分线距，就是先按**嘉立创 JLC04161H-3313 叠层**算出这个 H、
> 再反推线宽写进 PCB 规则的。

**嘉立创官方给的这套基准（可直接当对照表用）**：

| 项 | 值 |
|---|---|
| 外层成品铜厚 T1 | **1.6 mil** |
| 内层铜厚 | 0.5oz 按 **0.6 mil**；1oz 按 **1.2 mil** |
| 基材上防焊厚度 C1 | **1 mil**（2oz 厚铜板 1.2 mil） |
| 铜面上防焊厚度 C2 | **0.6 mil**（2oz 厚铜板 0.8 mil） |
| 线间防焊厚度 C3 | **1 mil**（2oz 厚铜板 1.2 mil） |
| 防焊 Dk（CEr） | **3.8** |
| 线顶宽度 | W2 = W1 − 0.5 mil |
| 板材 | 4–8 层默认 **南亚 NP-155F** |
| 叠构代号 | **JLC04161H-3313**（老的 2313 叠构与 3313 **厚度与 Dk 相同**） |

# 4. ⭐ 为什么这块板其实不用太担心（算给你看）

**MIPI DSI 的实际速率（按屏幕参数算）：**

```
分辨率 280 × 1424 = 398,720 像素
RGB888 = 24 bit/像素  →  9,569,280 bit/帧
60 fps             →  574 Mbps（合计）
÷ 4 lane           →  约 144 Mbps / lane
（若 30 fps → 约 72 Mbps / lane）
```

**144 Mbps/lane 对 MIPI D-PHY 来说是很低速的**（D-PHY 高速档可到每 lane 1 Gbps 以上）。
**另一条 SDIO（WiFi）也在几十 MHz 量级。**

**→ 结论**：这条链路对阻抗偏差的容忍度很大。
即使代工厂的叠层与嘉立创有中等差异，**最多是眼图余量变小，不会导致点不亮**——
这也正是作者原话"**不做其实也能正常跑起来，只不过速率受限而已**"的物理原因。

**所以处理策略是**：

| 情形 | 做法 |
|---|---|
| 拿到叠层表，L1→L2 介质厚度与嘉立创同档（大致 0.09–0.12mm）、铜厚一致 | ✅ **什么都不用改，直接生产** |
| 差异明显（比如差 30% 以上） | ⚠️ 也不用重新布线 —— **记下来，作为"第二版若做阻抗需重新算线宽"的备注** |
| 你想更保险 | 让他们按 §5 的话术给叠层表，你存档留证 |

---

# 5. ⭐ 直接可发的话术（等报价回来后再发也行）

```
对了，再跟您确认一个技术点（不影响报价）：

这块板 4 层 1.6mm，我这边不做阻抗管控，按你们的标准叠层做就行。

不过我的走线线宽是按某个叠层算的，想麻烦你们在下单/审单时给我一张
【叠层结构表】存档，我核对一下。需要这几项：

1. 每层的层名和属性（L1 顶层信号 / L2 GND / L3 VCC / L4 底层信号）
2. ⭐ L1 → L2 的介质厚度（压合后）
3. 外层 / 内层的成品铜厚
4. 板材型号和半固化片（PP）型号
5. 成品总厚及公差

我主要就看第 2 项（L1→L2 介质厚度），其它按你们的常规工艺走，
不需要为我改工艺、也不加阻抗管控。
```

**⚠️ 为什么强调"不影响报价""不加阻抗管控"**：
这两句能**防止客服顺手套一个"阻抗管控"的收费项**，也能防止他们为了迁就你而报高价。

# 6. 时间点提醒

| 阶段 | 要不要管叠层 |
|---|---|
| **现在（等报价）** | ❌ 不用管。报价级参数（4 层 / 1.6mm / 1oz / 尺寸 / 沉金）已经给全了 |
| **报价回来后比价** | ⚠️ 顺便看一眼有没有冒出"阻抗管控""指定叠层"之类的加价项 |
| **确认下单时** | ⭐ **要一张叠层结构表**存档（§5 话术） |
| **收板后** | 可留作答辩材料：说明"本版按标准叠层、未做阻抗管控，理由是速率余量充足" |

**⭐ 最后这条有额外价值**：答辩时如果被问"你为什么不做阻抗匹配"，
你现在的答案不是"为了省钱"，而是：

> "我按屏幕参数算了链路速率约 144 Mbps/lane，远低于该接口的速率上限，
> 阻抗偏差带来的眼图收缩有余量；作者样板的实测也印证了不做阻抗可以正常工作。
> 所以我把它列为第二版的可选优化项。"

**这是一个有量化依据的工程判断，比"作者说不做我也就不做"强得多。**
