| `6.esch` | SPI Flash |
| `7.esch` | MIPI 屏 + I2C 触摸屏 ← **参考它的 I2C 画法** |

### 2.2 ⭐ 重点观察第 7 页的 TP 电路（照抄它的画法）

打开第 7 页，找到 TP 部分，观察：

```
FPC7（6pin 触摸屏座）：
  1=TP_INT  2=TP_SDA  3=TP_SCL  4=TP_RST  5=3V3  6=GND

RN1（10kΩ 排阻，4 联）：
  TP_RST / TP_SCL / TP_SDA / TP_INT → 3V3
```

**⭐ 你的 TWI0 传感器电路照这个画**：端子 + 上拉电阻接 3V3。
**注意**：TP 用的是**排阻**（4 联一体），你的传感器只需 2 个上拉，**用两个独立 0603 电阻即可**。

### 2.3 确认四个目标引脚（已验证空闲，再看一眼）

在 `1.esch` 页搜索这四个引脚：**PE4、PE5、PG12、PG13**

| 引脚 | 用途 | 备注 |
|---|---|---|
| `PE4` | UART4-TX | 靠近 `PE` 区域的红色总线（VDD-PE 供电已画好） |
| `PE5` | UART4-RX | 同上 |
| `PG12` | TWI0-SCK | 在 `PG` 区域 |
| `PG13` | TWI0-SDA | 同上 |

**✅ 已于 2026-09-19 核实：四脚均无连接、无网络。**

## 第 4 步：新增 UART4（→ RV1106）★ 今天的主要工作

### 4.1 放置端子
```
放置 → 连接器/端子
推荐：ZX-MX1.25-3PWT（1.25mm 3P 卧贴）
  ⭐ 工程里已有这个器件，直接「复制」现有实例最省事
     （作者用它做了 UART3 调试口）
引脚分配：1=TX  2=RX  3=GND
```

### 4.2 连线

| 端子脚 | 接到 | 网络名建议 |
|---|---|---|
| 1 | `PE4`（UART4-TX） | `RV_UART_TX` |
| 2 | `PE5`（UART4-RX） | `RV_UART_RX` |
| 3 | `GND` | `GND` |

**交叉注意**：T113 的 **TX（PE4）要接 RV1106 的 RX**，别直连。

### 4.3 可选：串联电阻
```
在 PE4（TX）线上串 22–33Ω 电阻（抑制过冲），非必需
位置：靠近 T113 端
```

### 4.4 ⚠️ 电平确认
```
T113 侧：3.3V（PE bank 供电 VCC-PE = VCC-IO = 3.3V）
RV1106 侧：3.3V
→ 电平兼容，无需转换 ✅
```

## 第 5 步：新增 TWI0（I2C 传感器）★ 需传感器已选型

### 5.1 放置端子
```
4P 端子：1=VCC(3V3)  2=GND  3=SCL  4=SDA
```

### 5.2 连线

| 端子脚 | 接到 | 网络名建议 |
|---|---|---|
| 1 | `3V3` | `3V3` |
| 2 | `GND` | `GND` |
| 3 | `PG12`（TWI0-SCK） | `SENS_SCL` |
| 4 | `PG13`（TWI0-SDA） | `SENS_SDA` |

### 5.3 ⭐ 上拉电阻（关键）

```
放置两个 0603 电阻，4.7kΩ：
  SENS_SCL → 4.7kΩ → 3V3
  SENS_SDA → 4.7kΩ → 3V3

⚠️ 若传感器模块【自带上拉】，则先不焊或改用 10kΩ
   —— 并联后阻值会变小，过小会导致灌电流超限
```

**上拉计算依据**（3.3V、100kHz、C_bus ≈ 50pF）：

```
R_min = (3.3 − 0.4) / 3mA ≈ 967 Ω       （灌电流约束）
R_max ≈ 1µs / (0.8473 × 50pF) ≈ 23.6 kΩ （上升时间约束）
→ 可接受范围 1k ~ 24k，推荐 4.7kΩ
```

**💡 稳妥做法**：⭐ **预留焊盘先不焊**，调试时用示波器看上升沿，过缓再补焊。

### 5.4 若传感器有 ADDR 脚
```
查规格书决定：接 GND 还是接 VCC 决定 I2C 地址
→ 留一个可选的 0Ω 电阻位，方便后期改地址
```

## 第 6 步：连线后的自检（重要）

| # | 检查项 | 方法 |
|---|---|---|
| 1 | 四个引脚是否**确实没被别的网络占用** | 用「查找」搜 `PE4`/`PE5`/`PG12`/`PG13`，确认各只出现一次 |
| 2 | **网络名是否唯一** | 不要与已有网络重名（如别用 `UART4_TX` 若已存在） |
| 3 | TX/RX **是否交叉接错** | T113-TX → RV1106-RX |
| 4 | 上拉是否接到 **3V3** 而不是别的电源 | — |
| 5 | GND 是否连通 | 用「网络检查」 |
| 6 | **DRC 电气规则检查** | 工具 → 设计规则检查 |
| 7 | 是否误改了原有电路 | 与原始 V2 工程对比网络数（应只多不少） |

**⭐ 第 7 条最重要**：改完后**网络总数应该增加**（新增 `RV_UART_*`、`SENS_*`）。
若发现有网络减少，说明误删了东西。
