## 二、⭐ 三处引脚冲突与解法（这是本方案的核心）

### 冲突 1：UART5（PB4/PB5）与触屏 TWI1 共用引脚

**事实**（数据手册 p.40）：

| 引脚 | 复用功能 |
|---|---|
| PB4 | LCD0-D8 / I2S2-DOUT0 / **TWI1-SCK** / I2S2-DIN1 / LCD0-D20 / **UART5-TX** / CAN1_TX0 |
| PB5 | LCD0-D9 / I2S2-BCLK / **TWI1-SDA** / PWM0 / LCD0-D21 / **UART5-RX** / CAN1_RX0 |

**→ `PB4`/`PB5` 同时是 `TWI1` 与 `UART5` 的候选脚。**

**危险点**：若把 UART5 放在 PB4/PB5，则**这两个脚被 UART5 永久占用**。
将来若更换触摸屏（需要换用 TWI1 的另一组脚）、或增加第二个 I2C 设备（需要 TWI1），
就会与此冲突。

**解法**：⭐ **不用 UART5，改用 UART4 的 `PE4`/`PE5`** —— 与其他任何功能都不冲突。

### 冲突 2：UART4 首选脚 PB2 被功放使能占用

**事实**：`PB2` 被 `PA_SHDN`（功放使能）占用（硬件设计文档 L1661 明确）。

**解法**：⭐ **UART4 有第二组引脚 `PE4`/`PE5`**（数据手册 p.41），改用这组即可，
**不必改动功放电路**。

### 冲突 3：传感器需要 I2C，而触屏已占 TWI1

**解法**：⭐ **另开一条 I2C（TWI0），用 `PG12`/`PG13`**。

**为什么不用其他 TWI0 候选脚**：

| TWI0 候选脚 | 为何不选 |
|---|---|
| `PB2`/`PB3` | PB2 被功放使能占用 |
| `PE2`/`PE3` | 可能被 UART0 占用（文档记为 UART0 引脚） |
| `PF2`/`PF4` | 与 SDC0（Flash/存储）相关，风险高 |
| **`PG12`/`PG13`** ⭐ | **经 EDA 搜索确认：未连接任何网络** |

## 三、TWI0~TWI3 完整可用引脚组（数据手册 pp.40–42）

> 供后续调整用。**每个控制器都有多组备用脚，因此引脚冲突总是可解的。**

| 控制器 | 可用引脚组（SCK / SDA） |
|---|---|
| **TWI0** | `PB2/PB3` · `PE2/PE3` · `PD0/PD12` · **`PG12/PG13`** · `PF2/PF4` |
| **TWI1** | `PB4/PB5` · **`PE0/PE1`（触屏在用）** · `PG8/PG9` |
| **TWI2** | `PD20/PD21` · `PE4/PE5` · `PE12/PE13` · `PG6/PG7` · `PG14/PG15` |
| **TWI3** | `PB6/PB7` · `PC6/PC7` · `PE6/PE7` · `PG10/PG11` |

**⚠️ 注意**：`PE4/PB5` 既是 UART4 又是 TWI2 的候选脚；`PB4/PB5` 既是 UART5 又是 TWI1 的候选脚。
**同一引脚只能选一种功能** —— 本方案已按此原则避开所有重叠。

## 四、要新增的电路

### 4.1 UART4 串口端子（连 RV1106）

| 项 | 内容 |
|---|---|
| 信号 | `PE4` = T113 的 TX → RV1106 的 RX<br>`PE5` = T113 的 RX ← RV1106 的 TX |
| 端子 | 3P（TX / RX / GND），间距建议 1.25mm（与工程现用 `ZX-MX1.25-3PWT` 同系列，可复用封装） |
| 电平 | 3.3V（`VCC-PE` = VCC-IO = 3.3V），与 RV1106 的 3.3V 兼容 |
| 串联电阻 | 建议 TX 串 22–33Ω（抑制过冲），非必需 |
| 网络命名 | 建议 `RV_UART_TX` / `RV_UART_RX` / `GND` |

**⭐ 复用提示**：工程里已有 `ZX-MX1.25-3PWT`（1.25mm 3P 卧贴端子，见器件清单），
**可直接复制该器件，省去画封装**。作者也用同类端子做 UART3 调试口（`C7430469`）。

### 4.2 TWI0 传感器接口（I2C）

| 项 | 内容 |
|---|---|
| 信号 | `PG12` = SCL，`PG13` = SDA |
| 端子 | 4P（VCC / GND / SCL / SDA），建议同用 1.25mm 系列 |
| 供电 | `3V3` |
| 上拉 | ⭐ **见 §5 计算** |
| 网络命名 | 建议 `SENS_SCL` / `SENS_SDA` |

**⚠️ 为什么单独开一条 I2C 而不挂到触屏总线上**：

| 方案 | 优点 | 缺点 |
|---|---|---|
| 挂到触屏 TWI1（PE0/PE1） | 省一对引脚 | ⚠️ **需确认传感器地址不与触屏冲突**；一条总线出问题两个设备都挂 |
| ⭐ **另开 TWI0（PG12/PG13）** | **完全独立**，排查容易；引脚已确认空闲 | 多占一对引脚（但确实空着） |

**→ 推荐另开 TWI0。**

## 五、⭐ I2C 上拉电阻重新计算

### 5.1 现状（已从原理图确认）

```
RN1 = 10kΩ 排阻（4 联）
  ├─ TP_RST ─┐
  ├─ TP_SCL ─┤→ 3V3
  ├─ TP_SDA ─┤
  └─ TP_INT ─┘

FPC7 = AFC07-S06ECA-00（6pin）
  1=TP_INT  2=TP_SDA  3=TP_SCL  4=TP_RST  5=3V3  6=GND
```

### 5.2 ⚠️ 更正一处此前的判断错误

**迁移文档原写**：
> "触屏已有 10kΩ 上拉，**再加 4.7kΩ** 会导致总上拉约 **3.2kΩ**，可能过强。建议先不加自己的上拉。"

**实测结果**：工程里**只有 RN1 一组 10kΩ，没有 4.7kΩ**。
原文的 4.7kΩ 是**理论推算被误记为实装**。

**→ 结论要改**：
- 不是"加上拉会过强"
- 而是"**现有 10kΩ 上拉是唯一一组，新增 I2C 总线需要自己配上拉**"

### 5.3 TWI0（新总线）的上拉计算

**I2C 总线上拉的关键约束**：

| 约束 | 要求 |
|---|---|
| 上拉下限（**灌电流**） | `R_min = (VDD − VOL_max) / I_OL_max` |
| 上拉上限（**上升时间**） | `R_max ≈ t_r / (0.8473 × C_bus)` |

**本项目估算**（3.3V、标准模式 100kHz、总线电容约 50–100pF）：

| 参数 | 取值 |
|---|---|
| VDD | 3.3 V |
| VOL_max | 0.4 V |
| I_OL（3.3V 器件典型） | 3 mA |
| C_bus 估算 | 50 pF（短走线 + 1 个从器件） |

**计算**：

```
R_min = (3.3 − 0.4) / 0.003 = 967 Ω        → 上拉不得小于约 1 kΩ
R_max ≈ 1 µs / (0.8473 × 50 pF) ≈ 23.6 kΩ   → 上拉不得大于约 24 kΩ
```

**→ 可接受范围约 1 kΩ ~ 24 kΩ。推荐 4.7 kΩ**（居中，上升时间与功耗平衡）。

**🔲 待定项**：实际选值应在 PCB 布局完成后，按实际走线长度重新估算 C_bus。

**💡 实用建议**：⭐ **预留两个上拉焊盘但先不焊**（或焊 10kΩ），
调试时若示波器看到 SCL/SDA 上升沿过缓，再换 4.7kΩ。
**这比一次焊死更稳妥。**

## 六、V1 → V2 的 5 个删除网络（确认不影响本方案）

作者在 V2 中删除了以下 5 个网络（V2 相对 V1 **无任何新增**）：

| 删除网络 | 页面 | 含义 | 对本方案的影响 |
|---|---|---|---|
| `USB0_ID` | 4（USB） | USB0 的 OTG ID | ❌ 无影响 |
| `USB1_ID` | 4（USB） | USB1 的 OTG ID | ❌ 无影响 |
| `HPOUTL` | 5（音频） | 耳机左声道（保留 `HPOUTR`） | ❌ 无影响 |
| `LCD_VCC` | 7（屏幕） | 改用统一 `3V3` 命名 | ❌ 无影响 |
| `WIFI_VCC` | 2（WiFi） | 改用统一 `3V3` 命名 | ❌ 无影响 |

**→ 5 个删除全部与 UART / I2C / 引脚分配无关，本方案不受影响。**

**顺带理解的作者意图**：去掉 OTG ID（不再需要 OTG 切换）、改单声道音频、合并电源命名 ——
这些正是官方所述"V2 优化了功放发热、LDO 发热问题"的来源。

## 九、焊接分工建议

| 类别 | 建议方式 | 理由 |
|---|---|---|
| **T113S3（LQFP128，0.4mm 间距）** | ⭐ **交 SMT** | 128 脚 QFP 手工焊接风险高 |
| **RTL8723DS（44P，0.9mm 间距）** | ⭐ **交 SMT** | 模组类器件回流焊更可靠 |
| **MIPI FPC 座（0.5mm 间距）** | 交 SMT 或**实验室热风** | 0.5mm 座子需热风 |
| **Type-C（16P/6P）** | 实验室可行 | 间距大 |
| **阻容（0603/0402）** | 实验室可行 | 0402 需一定功底 |
| **电源芯片（SOT23-6 等）** | 实验室可行 | — |
| **端子（1.25mm 贴片）** | 实验室可行 | — |

**⭐ 策略建议**：**核心器件交 SMT（省时省风险），端子与阻容自己焊（导师提供实验室）**。
这样一次打样就能验证，不必因为焊接不良重打。
